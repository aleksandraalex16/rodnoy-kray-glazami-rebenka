# Родной край — глазами ребенка

Сайт Республиканского конкурса детского творчества для участников клубных формирований учреждений культурно-досугового типа Луганской Народной Республики.

## Содержание

- условия и направления конкурса;
- четыре конкурсные номинации;
- порядок участия и требования к работам;
- критерии оценки;
- положение о конкурсе в формате DOCX.

Сайт является статическим и не требует сборки. Главная страница: `index.html`.
